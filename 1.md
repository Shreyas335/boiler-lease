## Project Overview

Boiler Lease is a sublease management platform with a Django REST Framework backend and React/TypeScript frontend, orchestrated with Docker Compose.

## Common Commands

### Docker (Primary Development)
```bash
docker-compose up --build                                    # Start all services
docker-compose exec backend python manage.py migrate         # Run migrations (required after first start)
docker-compose exec backend python manage.py createsuperuser # Create admin user
docker-compose exec db psql -U app_user -d app_db            # Database shell
```

### Frontend (cd frontend/)
```bash
npm run dev      # Vite dev server (localhost:5173)
npm run build    # TypeScript compile + Vite build
npm run lint     # ESLint
```

### Backend (cd backend/)
```bash
python manage.py runserver   # Dev server (localhost:8000)
python manage.py migrate     # Apply migrations
python manage.py makemigrations accounts  # Create new migrations
```

## Architecture

### Backend Structure (Django)
- `backend/config/` - Django settings, root URLs, WSGI/ASGI
- `backend/accounts/` - All models, views, serializers (monolithic app containing users, listings, amenities, media, feedback)

**Key Models:**
- `User` - Custom user with types: SUBLESSEE, SUBLEASER, MANAGEMENT; includes email verification and 2FA fields
- `PropertyListing` - Listings with status (DRAFT/PUBLISHED/UNPUBLISHED/ARCHIVED) and approval status (PENDING/APPROVED/REJECTED); soft-deleted via `deleted_at`
- `ListingAmenity` / `ListingAmenityMap` - Many-to-many amenities
- `ListingMedia` - Images/videos for listings

### Frontend Structure (React + TypeScript + MUI)
- `frontend/src/api/` - Axios clients (`axios.ts` handles CSRF, `auth.ts`, `listings.ts`)
- `frontend/src/contexts/AuthContext.tsx` - Global auth state via React Context
- `frontend/src/pages/` - Route components
- `frontend/src/components/` - Shared components including `ProtectedRoute.tsx`

### API Communication
- Session-based authentication with CSRF protection
- Frontend calls `/api/auth/csrf/` before auth operations to get CSRF cookie
- Axios configured with `withCredentials: true` and reads CSRF token from cookie
- Vite proxies `/api/*` to backend in development

### Key API Endpoints
```
POST /api/auth/register/           # Register
POST /api/auth/login/              # Login (may return requires_2fa)
POST /api/auth/2fa/                # Verify 2FA code
GET  /api/account/                 # Current user profile
POST /api/listings/                # Create listing (SUBLEASER only)
GET  /api/listings/mine/           # User's listings
GET  /api/listings/browse/         # Public browse with filters
```

## Access Points
- Frontend: http://localhost:5173
- Backend API: http://localhost:8000/api
- Django Admin: http://localhost:8000/admin

## Database
PostgreSQL 15 in Docker (falls back to SQLite if env vars not set). Redis for caching/2FA codes.
